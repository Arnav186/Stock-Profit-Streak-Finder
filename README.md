# Stock Profit Streak Finder

The Stock Profit Streak Finder is a dynamic web-based visualization tool that simulates stock market data and identifies the most profitable continuous streak of price increases using Kadane’s Algorithm. The project showcases both algorithmic logic and creative UI design.

## Features
- Random stock price generator
- Dynamic Chart.js visualization
- Animated shaded highlight for best profit streak
- Responsive dark theme UI

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js library

## How to Run
1. Clone the repo  
   ```bash
   git clone https://github.com/yourusername/stock-profit-streak-finder.git
   ```
2. Open `index.html` in a web browser.
3. Click **Generate Random** then **Analyze**.

## Algorithm
Implements **Kadane’s Algorithm** to find the maximum profit streak from simulated stock data.
